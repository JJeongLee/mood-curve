# 2026 셀프 연말정산 · 모각회 자료

「2026 셀프 연말정산 · 모각회(모여서 각자 회고)」에서 쓰는 자료 3종이에요. 노트북 브라우저에서 바로 쓸 수 있어요.

| 자료 | 언제 쓰나요 | 링크 |
|---|---|---|
| ① 2026 나의 기분 곡선 | 몰입1 · 1~12월 기분 곡선과 월별 기록 | [바로 쓰기](https://jjeonglee.github.io/self-retro/) |
| ② 회고 템플릿 | 몰입2 · 템플릿 5종 중 하나 + 마무리 2027 예산안 | [바로 쓰기](https://jjeonglee.github.io/self-retro/templates.html) |
| ③ 회고 질문 카드 | 쓰다가 막힐 때 한 장씩 뽑는 질문 30장 | [바로 보기](https://jjeonglee.github.io/self-retro/cards.html) |

## ① 2026 나의 기분 곡선

- 1~12월마다 기분 점수(1-5)를 고르거나 그래프를 눌러 점을 찍으면 곡선이 그려져요.
- 달마다 기억에 남는 일을 한 줄씩 적고, 곡선을 보며 회고 질문 세 개에 답해요. 글이 길어지면 칸이 늘어나요.
- 쓰는 내용은 **내 노트북 브라우저에만** 자동 저장돼요. 서버로 보내지 않아요. 같은 노트북에서 다시 열면 이어서 쓸 수 있어요.
- 다 쓰면 **이미지로 저장**을 눌러 PNG 한 장으로 받아 두세요. 브라우저 기록을 지우면 저장된 내용도 사라져요.

## ② 회고 템플릿

- 연말정산서 · KPT · 4L · WWA · 올해의 키워드와 문장 중 하나를 골라 쓰고, 마지막에 2027 예산안을 써요.
- 쓰는 내용은 **내 노트북 브라우저에만** 자동 저장돼요. 다 쓰면 **이미지로 저장**하거나 **글로 복사**해 메모 앱에 붙여 두세요.

## ③ 회고 질문 카드

- **한 장 뽑기**를 누르면 질문이 한 장씩 나와요. 분류(처음과 새로움 · 사람 · 순간과 감정 · 내려놓기와 내년)별로 뽑을 수도 있어요.

## 파일

- `index.html` : 기분 곡선 워크시트.
- `templates.html` : 회고 템플릿. `cards.html` : 질문 카드.
- `index.html`의 제목·서명 줄은 나눔명조 일부 글자판(`nm-*.woff2`, SIL OFL 1.1)을 써요. 라이선스는 `OFL-NanumMyeongjo.txt`
- `html2canvas.min.js` : 이미지 저장 도구 (html2canvas 1.4.1, MIT). 라이선스는 `LICENSE-html2canvas.txt`
- `fonts.css`, `sck-sans-*.woff2` : 본문 글꼴 (IBM Plex Sans KR 부분 글꼴, SIL OFL 1.1). 라이선스는 `OFL-IBM-Plex-Sans-KR.txt`

외부 서버에서 아무것도 불러오지 않아요.
